# Koopman Operator Theory for Control &mdash; Tutorial Toolbox

This code accompanies the tutorial session and paper
*"Koopman operator theory: fundamentals, control, and applications"* presented at the IEEE International Conference on Decision and Control, 2026. 

The toolbox is structured into the following two parts:

## EDMD for Autonomous Systems

The code in this folder provides an introduction into learning Koopman operator approximations for autonomous systems using EDMD. It illustrates different dictionary choices, demonstrates how a linear predictor is constructed, and how eigenfunctions can be approximated. 

**Contact:** This part of the KOT Toolbox is maintained by Armin Lederer (National University of Singapore), armin.lederer@nus.edu.sg. Questions and issues are welcome.



## Koopman MPC

The code in this folder serves as an introduction to learning Koopman operator models for systems with control inputs and their usage in model predictive control (MPC). It compares different extensions for Koopman operator models to systems with control inputs.


**Contact:** This part of the KOT Toolbox is maintained by Mircea Lazar (TU Eindhoven), m.lazar@tue.nl. Questions and issues are welcome.
